The five it most resembles

800 real handwritten digits, written by 43 people for the UCI optical-recognition dataset. On that dataset’s own held-back images this method gets 98% right — on a finger-drawn squiggle, considerably less, because you do not write like those 43 people.

The problem it solves

Try writing down what a 7 is

Every rule you can state, a real person’s handwriting breaks. This is not a hard problem to describe — it is a problem that cannot be described.

Rules a person typed
a horizontal stroke on top✗ so has a 5, and a 2
…plus a diagonal going down-left✗ many people write it straight
…and no closed loop✗ so has a 1, and a 4
…and no crossbar✗ half of Europe crosses their 7

Each patch breaks something that worked before. The rulebook never converges.

Patterns learned from examples

Forty of the 800. Nobody described a single one — a person just wrote down which digit it was, and the machine measures its way to the rest.

It cannot tell you it doesn’t know

Go back up and draw a letter, a star, or a scribble. It will still answer with a digit, and it will look just as sure as before.

There is no “none of the above” anywhere in the machine. It was built to return its closest match, so a closest match is always what you get — a habit worth remembering when a much larger model answers a question it has no business answering.

So what

Photo search, face unlock, fraud alerts — all the same move: turn it into numbers, compare it to labelled examples, take the vote.
