The problem this replaces

Same six things, no fixed order

Everyone touches the same six things — but in a different order, on a different day, with no way to point at where the ticket actually is.

How it works

Each station requires the last one's stamp

See it in action

One ticket, six stamps

Same six stamps, every time — whichever developer runs the command.

So what
