The context window

The model has no memory of your conversation. It has a desk — what's technically called the context window — and everything on it gets re-read before every word, right up to the desk's own edge.

The problem it explains

It doesn’t remember. It re-reads.

People assume the model carries the conversation with it. Nothing carries over — the entire transcript is handed back in, from the top, before each new word.
