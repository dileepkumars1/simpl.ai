Turning human preference into a training signal

Be the rater. Pick whichever reply you'd rather get — do it a few times and watch a separate reward model learn the pattern, then watch that pattern start steering the main model's default reply.

Hand-simulated with a simple counter, not a real reward model — real training uses many thousands of rated pairs, not a handful of clicks.

How it works

The rating never touches the model directly

The main model never "reads" a rating. It is nudged by a score from a model that was itself trained to imitate the pattern in thousands of human choices.

So what

Whatever gets picked most often becomes the default — not because it is right, but because it is what a proxy trained on those choices learned to score highest.
