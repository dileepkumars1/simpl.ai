Deepens pages 57 & 58

The same trick, pointed at a real face

A deepfake uses the exact same face-mapping mechanism as a cartoon filter — find the landmarks (eyes, nose, mouth), map them onto a target, redraw. The only difference is how realistic that target is trained to look. Same mapping, both times.

How it works

Find the landmarks, map them over

So what

A face filter and a deepfake are the same three steps — only how convincing the last step is meant to be changes.
